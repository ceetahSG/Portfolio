## 3) Pin Your Best 6 Repositories

Use this exact 6-slot mix:

1. **Flagship practical app** (real users/problem)
2. **Strong DB/system design project**
3. **One community-impact project**
4. **Portfolio/personal website**
5. **One technical depth project** (algorithms, architecture, infra)
6. **One “in progress” growth repo** (shows consistency)

### Selection rule
Only pin repos that have:
- clear README
- demo/screenshot/GIF
- setup steps
- outcomes/impact statement

---

## 4) Upgrade Every Pinned Repo (Checklist)

For each pinned repository, ensure:

- [ ] Clear **Problem** section
- [ ] Clear **Solution/Approach** section
- [ ] **Tech Stack** listed
- [ ] **Setup & Run** instructions
- [ ] **Demo** link and/or screenshots/GIFs
- [ ] **Results/Impact** (speed, usage, accuracy, time saved, etc.)
- [ ] Relevant GitHub **Topics/Tags**
- [ ] Clean issue labels
- [ ] Maintain tidy commits (clear messages, avoid frequent WIP/noise commits on default branch)

---

## 5) Credibility Signals to Add

Add measurable proof wherever possible:

- Events delivered (e.g., major broadcast productions)
- Scale handled (e.g., match data volume, participants, uptime)
- Recognition/certificates/awards
- Open-source or community contributions (PRs, issues, discussions)

### Impact statement format
Use: **Action + Scope + Result**
- Example style: “Led X for Y-scale event, resulting in Z reliability/quality outcome.”

---

## 6) Visual Cleanliness Rules

Keep your profile readable and professional:

- short sections, clear headings, bullet points
- consistent icon style (don’t overuse)
- no cluttered badge walls
- prioritize content quality over too many widgets
- keep featured projects concise and impact-first

---

## 7) Activity System (Weekly/Monthly)

### Weekly
- push at least one meaningful commit to a real repo
- improve one README section or add one visual demo
- engage in 1–2 relevant issues/discussions/PR reviews

### Monthly
- refresh pinned repositories
- archive or unpin stale/weak projects
- update profile intro/achievements with latest outcomes
